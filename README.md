# 🤖 AI Resume Analyzer (MERN + Gemini AI)

An advanced, full-stack AI-Powered Resume Analyzer designed to bridge the gap between job seekers and their dream roles. Users can upload their resumes, paste job descriptions, and get a deeply personalized evaluation report, interview preparation material, and a customized learning roadmap—all generated using Google's Gemini Flash Preview API.

---

## 🚀 Key Features

*   **🔐 User Authentication:** Secure User Signup and Login system to save and manage personalized reports.
*   **📊 Comprehensive Match Score:** Analyzes the resume against the job description and self-description to calculate an accurate ATS compatibility percentage.
*   **💡 Skill Gap Analysis:** Identifies critical technical and soft skills missing from the resume based on the targeted job description.
*   **🎯 Tailored Interview Preparation:**
    *   **Technical Questions:** Generates role-specific technical interview questions.
    *   **Behavioral Questions:** Generates situation-based questions to ace HR rounds.
*   **📅 Day-Wise Learning Schedule:** Generates a structured, day-by-day roadmap/schedule to learn and bridge the identified skill gaps effectively.

---

## 🛠️ Tech Stack

### Frontend
*   **React.js** - For building a dynamic and responsive User Interface.
*   **Tailwind CSS** - For modern, clean, and sleek styling.

### Backend
*   **Node.js & Express.js** - To handle robust API routing and server-side logic.
*   **MongoDB** - For secure user data and report storage.

### AI Integration
*   **Google Gemini Flash Preview API** - For high-speed, intelligent text parsing and deep analytical report generation.
